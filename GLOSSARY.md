# Portfólio Eduardo Soldi Junior

Site pessoal que apresenta Eduardo Soldi Junior a recrutadores e potenciais clientes: quem ele é, o que sabe fazer e o que já construiu.

## Language

**Projeto**:
Um trabalho real de Eduardo exibido na seção de projetos, descrito sem inventar clientes, números ou resultados.
_Avoid_: case, portfólio (para um item individual)

**Projeto sem código público**:
Um projeto real, corporativo ou acadêmico, cujo código não pode ser mostrado; é apresentado só pela descrição, sem link de repositório.
_Avoid_: projeto sem link, projeto privado, projeto "#"

**Origem**:
De onde um projeto veio, e por isso se o código pode ou não ser mostrado. Cada projeto tem exatamente uma origem: código aberto, corporativo ou acadêmico.
_Avoid_: tipo, categoria

**Código aberto**:
Origem de um projeto cujo repositório é público e pode ser lido e clonado por qualquer pessoa.
_Avoid_: open source (no texto do site), público

**Corporativo**:
Origem de um projeto feito no ambiente de trabalho de Eduardo, mesmo quando por iniciativa própria; o código pertence ao contexto da empresa e não é mostrado.
_Avoid_: profissional, interno, privado

**Acadêmico**:
Origem de um projeto feito como parte da formação, por exemplo o projeto integrador da FATEC.
_Avoid_: faculdade, estudo
